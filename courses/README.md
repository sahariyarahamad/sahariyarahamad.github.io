# Courses System

Updated version: course-specific CSS/JS are externalized to `assets/css/courses.css` and `assets/js/courses.js`. Curriculum uses native `<details>/<summary>` dropdowns with JS enhancement. No dashboard, admin panel, payment backend, JSON, or database is included.

Replace `VIDEO_ID` values in `assets/js/courses.js` with real YouTube IDs, or use a self-hosted `<video>` element on a lesson page.
